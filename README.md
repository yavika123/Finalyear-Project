Smart Complaint Tracking & Escalation System

📌 Project Description
     A web-based application designed for complaint registration, tracking, and automatic escalation. 
     This system helps streamline public grievance handling efficiently.

🚀 Features
     Complaint Registration
     Real-time Status Tracking
     Auto Escalation System
     Role-Based Access Control (Admin/User)

🛠️ Technologies Used
    Frontend: HTML, CSS, JavaScript
    Backend: JavaScript

🎯 Objective
    To improve transparency and efficiency in complaint resolution systems.
